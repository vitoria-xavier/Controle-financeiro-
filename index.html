Projeto em destaque

Controle Financeiro

Aplicação web desenvolvida para organizar e acompanhar movimentações financeiras de forma simples e intuitiva. Permite registrar receitas e despesas, calcular automaticamente o saldo e acompanhar um resumo financeiro. Os dados são armazenados localmente no navegador.

Cadastro de receitas Cadastro de despesas Cálculo automático Resumo financeiro Armazenamento local Layout responsivo
Tecnologias: HTML5 • CSS3 • JavaScript • LocalStorage
